MOTOCROSS MADNESS 2 - UNIVERSAL HOST
www.siljo-planet.net

UPORABA
1) Razzipaj kamorkoli (npr. D:\Games\mcm2)
2) Zaženi HOST.bat
3) Ob prvem zagonu preveri izbiro MCM2.EXE
4) Prvič vpiši Base URL (npr. https://www.siljo-planet.net) -> shrani se v base_url.txt
5) Ustvari Room, dobiš Room Code -> deli s soigralci
6) V igri izberi: Start Network Play (IPX / LAN)

OPOMBE
- Skripta samodejno zapiše veljaven ipxwrapper.ini ter nastavi poti v registru:
  [global]
  port=PORT

USTAVI HOST
- STOP_HOSTING.bat

RESET
- RESET_PATH.bat (pozabi shranjeno pot do igre)
- RESET_HOST_ROOM.bat (pozabi zadnjo host sobo)
